# ACE-Senior-Project

This repository contains my ACE-CYBER senior research project, Contextualized Threat Intelligence Prioritization for CTI Analysts. The project focuses on using automated contextual scoring to classify synthetic security logs into HIGH, MEDIUM, and LOW priority levels to improve threat identification efficiency.

## Repository Structure

- **Documentation:** Contains the project's research documents, including the project charter, research design, test plan, research notebook, data analysis, and white paper.
- **Source-Code:** Contains the Bash log generation script, Kibana runtime field scoring script, Docker Compose configuration, and Filebeat configuration.
- **Screenshots:** Contains screenshots of the testbed setup, log generation, runtime field implementation, and HIGH, MEDIUM, and LOW priority results.
- **Test-Results:** Contains summaries of the three test cases: manual baseline analysis, automated contextual prioritization, and high-volume log testing.
